# Learning Log

## Phase 1: Console app (26 Nov 2026)

- During phase 1 of building, I learned TryParse, which is essentially a method that converts a string into an integer and stores the converted value on the out parameter.
- I learned about namespaces in C#; I learned that they are no different from packages in Java where you keep classes with related functionalities together.
- I also learned about the methods, OrderBy, Where and FirstOrDefault which come in handy when I want to organize the output in a specific manner.

- **TryParse:** converts text into another type (int, DateTime) without
  crashing if the text is invalid. It returns "true" or "false" and passes the
  converted value back through the "out" parameter.
- **Namespaces:** work like Java packages. They group related classes together.
- **LINQ methods:** "OrderBy" sorts stuff, "Where" filters, and "FirstOrDefault"
  finds the first match (or null). These allow me to shape the output without hassle.
